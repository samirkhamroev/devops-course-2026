1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
Ответ:В Git ветвление происходит мгновенно, так как это просто создание легковесного указателя на коммит. В SVN оно «дорогое» и медленное, потому что под капотом происходит физическое копирование директорий проекта.


2. Можно ли в SVN сделать коммит без интернета? Почему?
Ответ:Нет. SVN имеет централизованную архитектуру, где существует только один центральный сервер. Без сети разработчику доступны только локальные изменения, а для фиксации коммита в историю требуется обязательное подключение к серверу. В отличие от этого, Git хранит полную копию репозитория у каждого пользователя.


3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
Ответ:SVN применяется для поддержания старых (legacy) систем. Чаще всего это крупные исторические проекты в консервативных сферах, таких как госсектор и банки. Все новые проекты сегодня стартуют на Git.
